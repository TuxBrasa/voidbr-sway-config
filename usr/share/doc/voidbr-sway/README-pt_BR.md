# VoidBR Sway


Personalização da ISO do Void Linux para o ambiente gráfico Sway, proporcionando uma experiência leve, 
minimalista e altamente configurável baseada no Wayland.

O projeto reúne configurações, scripts, temas, pacotes e demais ajustes necessários para 
disponibilizar uma experiência integrada do Sway no Void Linux, adaptada às necessidades 
e à identidade do projeto VoidBR.


## Objetivos

Disponibilizar uma ISO do VoidBR com o Sway pré-configurado.
Oferecer uma experiência Wayland leve e funcional desde a instalação.
Centralizar configurações e personalizações do ambiente Sway.
Facilitar a instalação e configuração para novos usuários.
Manter a personalização alinhada à filosofia de simplicidade e flexibilidade do Void Linux.

## Componentes

A personalização pode incluir configurações do Sway, Waybar, terminal, lançador de programas, 
gerenciamento de wallpapers, atalhos de teclado, temas, fontes, notificações, utilitários 
Wayland e demais ferramentas necessárias para compor o ambiente.

O VoidBR Sway é desenvolvido como parte do ecossistema VoidBR, utilizando o Void Linux como 
base e buscando oferecer uma experiência simples, leve e pronta para uso.


VoidBR Sway - Void Linux + Wayland + Sway, do jeito brasileiro.
